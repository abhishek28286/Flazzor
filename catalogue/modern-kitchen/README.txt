# Modern Kitchen / Interior Demo Flipbook

Upload the `catalogue/modern-kitchen/` folder into the root of your website's GitHub Pages main branch.

Live path:
https://flazzor.in/catalogue/modern-kitchen/

The flipbook uses the PageFlip JavaScript library from jsDelivr CDN. Internet access is required for the page-turn library.
Images are stored locally in `assets/`.

Note: Browser-side restrictions discourage right-click, text selection and dragging, but cannot prevent screenshots, screen recording, developer-tools access, or all image extraction.
